# Ausbildung Budget Manager 🇩🇪

Приложение для управления бюджетом во время обучения (Ausbildung) в Германии.

## Возможности
- Расчет ежемесячного бюджета (по умолчанию 1100€)
- Учет расходов: еда, жилье, транспорт, инвестиции
- Цветовые предупреждения при превышении бюджета
- Индикатор финансовой безопасности

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/georgeusaaa/ausbildung-budget-manager.git

# Перейти в папку
cd ausbildung-budget-manager

# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python budget_manager.py
